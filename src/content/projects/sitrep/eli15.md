Ask three teams what “activation” means. You will get three answers. Dashboards will still print one number as if they agreed.

DriftGuard is a SitRep agent that runs after meetings. It extracts working definitions, compares them to everything it has seen before, and flags the disagreements a normal summary misses: definition drift, a value that moved because the meaning moved, and two teams using the same name differently.

What it produces is Markdown: a DriftGuard report and a living metric glossary with aliases, owners, history, and open conflicts. Memory is the product. Meeting one starts a glossary; meeting twenty holds history nobody can reconstruct from chat.

Who is this for? Operators who are tired of arguing about the number after the number has already been used.
