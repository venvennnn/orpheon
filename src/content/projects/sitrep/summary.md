DriftGuard is a SitRep agent that runs after meetings. It extracts working definitions, compares them to everything it has seen before, and flags the disagreements a normal summary misses.

### Memory is the product
Meeting one starts a glossary. Meeting twenty holds history nobody can reconstruct from chat.

### Three failure modes
Definition drift. Confounded value changes. Cross-team conflicts on the same name.

### Markdown you can keep
A DriftGuard report and a living metric glossary with aliases, owners, history, and open conflicts.
